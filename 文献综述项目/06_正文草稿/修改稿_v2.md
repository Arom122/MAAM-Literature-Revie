# 引言写作底稿 v2（用于投稿版收敛）

## Reviewer-oriented gap statement（可直接移植）
尽管 non-planar extrusion AM 已在路径生成与几何可达性方面取得进展，现有文献仍缺少一个将 **local geometry → process parameters → resulting bead/stability** 端到端联动的逆向规划框架。特别是，自动化测量与高通量数据基础设施尚未与 non-planar 工艺建模深度耦合，导致多数参数研究仍停留在经验窗口与试错优化，难以实现可迁移的参数反演能力。

## Novelty statement（可直接移植）
本文提出一套 geometry-aware、high-throughput、physics-informed 的 non-planar extrusion inverse process-planning framework：
1. 以曲面局部几何（坡度/曲率）为条件变量统一描述工艺空间；
2. 以自动化计量与数据流水线支持高覆盖实验与可追溯证据；
3. 以双向/逆向建模连接质量预测与参数回推；
4. 以 framework 形式桥接 planar process control 与 non-planar geometric fabrication。

## Contribution framing（可直接移植）
- C1：提出面向 non-planar extrusion 的 geometry-aware 参数—几何耦合描述与问题定义。
- C2：构建自动测量+高通量数据采集流程，为逆向规划提供数据基础。
- C3：建立 physics-informed/data-driven 双向建模与逆向参数生成策略。
- C4：给出与路径生成主导文献和经验参数研究文献的系统对比，明确本文边界与增量。
