# 纳入与排除标准（面向 framework paper）

## 纳入标准
1. 主题与以下至少一组强相关：A/B/C/D/E。
2. 时间以 2020–2026 为主；2020 前仅纳入明确“奠基性”工作。
3. 优先英文国际期刊/会议，且可获取可信题录信息（题目、作者、年份、来源）。
4. 能为以下任一论点提供证据：
   - non-planar 价值与应用场景；
   - 现有 non-planar 研究路径主导；
   - 参数研究经验化；
   - planar 已形成 sensing–modeling–control 方向；
   - geometry-aware inverse framework 仍缺失。

## 排除标准
1. 与 extrusion AM 或 process planning 关联弱。
2. 仅概念宣传、无方法或实证信息。
3. 同主题重复度高且证据增量不足。
4. DOI、来源、年份长期无法核验（保留“待核验”但不入核心层）。

## 证据等级（当前执行）
- L1：题录级（标题/作者/年份/来源）
- L2：摘要级（可提取方法与主要发现）
- L3：全文级（可用于核心论证与图示）

> 当前已完成 L1+部分 L2；后续将推进核心文献到 L3。
